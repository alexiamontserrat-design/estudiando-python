# estudiando-python

Proyecto educativo para organizar el aprendizaje de Python.

## Problema y objetivo

### Problema

Los estudiantes que comienzan a aprender Python pueden
tener dificultades para identificar su nivel de
conocimientos y organizar los temas que necesitan estudiar.
Esto puede provocar confusión al elegir materiales de
aprendizaje.

### Objetivo

Diseñar una herramienta educativa que clasifique a los
estudiantes en tres niveles de conocimiento de Python
mediante un cuestionario diagnóstico inicial.

### Siguiente paso

Diseñar un cuestionario de 10 preguntas sobre conceptos
básicos de Python para identificar el nivel inicial
de los estudiantes.
